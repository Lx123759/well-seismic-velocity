## 1 引言

### 1.1 编写目的

本文档明确系统的功能需求、非功能需求、数据需求和外部接口，作为设计、编码、测试与验收的依据。读者为开发者本人、指导教师和测试人员。

### 1.2 范围

系统是一套单机桌面软件，读入地震剖面、测井曲线和井位，完成测井预处理与井震标定，分别用传统插值方法和测井约束 U-Net 建立二维速度场，并对结果进行可视化、精度评估与导出。

本版本不包括：三维速度建模、叠前数据处理、全波形反演、多用户协同与网络服务。

### 1.3 术语

| 术语 | 说明 |
|---|---|
| Vp | 纵波速度，单位 m/s |
| DT / DTC | 声波时差，单位 μs/ft，Vp = 304800 / DT |
| 粗化 | 把测井曲线平滑、重采样到地震尺度（滑动平均或 Backus 平均） |
| 井旁道 | 井位投影到地震网格后，最近的一道地震数据 |
| 伪井 | 在已知速度模型中抽取的若干道，模拟测井速度 |
| 盲井 | 不参与训练与插值、只用于检验的井 |
| 低频背景模型 | 由井点速度插值得到的平滑速度场 |
| 井位掩码 | 与剖面同尺寸的二值图，井所在道为 1，其余为 0 |

## 2 总体描述

### 2.1 产品定位

商业解释软件的速度建模功能封闭、昂贵，难以嵌入深度学习；开源工具 VelRecover 只做速度拾取点插值，不使用测井和地震结构信息；学术代码多为脚本，缺少数据管理与评估界面。本系统把"测井约束 + 地震结构引导 + 深度学习"做成可交互的开源桌面软件，并内置传统方法作为对照。

### 2.2 用户

| 用户 | 特点 | 主要诉求 |
|---|---|---|
| 物探处理解释人员（主要） | 熟悉地震与测井，不一定会编程 | 导入工区数据，快速得到速度场并知道它有多可靠 |
| 科研人员与学生（次要） | 会编程，关注方法对比 | 在统一平台上对比插值方法与深度学习方法 |

### 2.3 运行环境

- 操作系统：Windows 10/11（64 位）
- 运行时：Python 3.10 及以上；发布版为 PyInstaller 打包的可执行程序
- 硬件：内存 ≥ 8 GB；推荐 NVIDIA 显卡（显存 ≥ 6 GB），无显卡时用 CPU

### 2.4 约束与假设

- 只处理二维剖面，速度与地震统一为深度域、（道, 深度）排列。
- 真值已知的合成模型（官方 Marmousi2 及其配套合成地震）用于训练和定量评估；真实测井数据只用于预处理验证与演示，定量结论以合成模型为准。
- 原始数据只读，所有处理结果另存。

### 2.5 业务流程

新建工程 → 导入数据 → 预处理与井震标定 → 构建初始模型 → 训练或加载 AI 模型并预测 → 评估与对比 → 导出成果。

## 3 功能需求

优先级：高 = v0.1/v0.2 必须完成；中 = v1.0 前完成，进度紧张时可简化。

### F1 数据管理（高）

| 编号 | 需求 |
|---|---|
| F1.1 | 新建、打开、保存、关闭工程；工程保存为一个目录，内含 SQLite 工程库和结果文件 |
| F1.2 | 导入地震剖面与速度模型：SEG-Y（rev1）、NPY、BIN（float32，需用户给出形状） |
| F1.3 | 导入测井：LAS 2.0、CSV（需指定深度列和曲线列）；导入井位坐标（CSV） |
| F1.4 | 数据列表：显示名称、类型、道数、采样点数、采样间隔、网格范围、数值范围 |
| F1.5 | 导入校验：格式能否解析、维度是否匹配、数值是否在合理范围（Vp 300～8000 m/s），不通过时拒绝导入并说明原因 |

输入：数据文件路径及必要参数。输出：工程库中的数据体、井、测井曲线记录。

### F2 数据预处理与井震标定（高）

| 编号 | 需求 |
|---|---|
| F2.1 | 测井清洗：识别 -999.25 等空值；按合理范围（DT 40～200 μs/ft）和滑动中值法剔除尖峰；对不超过设定长度的缺失段做线性插补 |
| F2.2 | DT → Vp 换算：Vp = 304800 / DT |
| F2.3 | 测井粗化：滑动平均或 Backus 平均，窗口长度可设；粗化后重采样到地震深度网格 |
| F2.4 | 井位投影：按坐标把井投影到剖面最近道，记录道号；提取井旁道 |
| F2.5 | 地震预处理：振幅归一化（最大值或标准差）、去除全零道、网格重采样 |
| F2.6 | 处理前后对比显示 |

### F3 初始速度模型构建（中）

| 编号 | 需求 |
|---|---|
| F3.1 | 基于井点速度进行 IDW 插值（幂次可设） |
| F3.2 | 普通克里金插值（变差函数模型可选：球状、指数、高斯） |
| F3.3 | RBF 插值（核函数可选） |
| F3.4 | 可选高斯平滑，输出低频背景速度模型 |
| F3.5 | 结果既作为 AI 网络输入通道，也作为精度对比基线 |

插值方式：按深度逐层对井点速度做横向插值（二维剖面中井为若干道）。

### F4 AI 井震联合速度建模（高）

| 编号 | 需求 |
|---|---|
| F4.1 | 样本生成：从已知速度模型中随机抽取 N 口伪井（N 可设），计算低频背景模型与井位掩码，随机切片（切片尺寸可设），数据增强（左右翻转、振幅扰动、加噪） |
| F4.2 | 网络：测井约束 U-Net，输入三通道（归一化地震振幅、低频背景速度、井位掩码），输出速度场 |
| F4.3 | 损失：L = MSE + λ·MSE_well，λ 可设 |
| F4.4 | 训练：可设学习率、批大小、轮数；后台线程运行；实时显示训练与验证损失；定期保存检查点，可从检查点继续训练；可中止 |
| F4.5 | 设备：自动检测 GPU，无 GPU 时回退 CPU |
| F4.6 | 预测：加载权重，对整条剖面预测速度场（滑窗拼接），结果存为新的数据体 |

### F5 结果可视化与精度评估（高）

| 编号 | 需求 |
|---|---|
| F5.1 | 显示速度剖面、地震剖面、误差剖面；色标、范围可调；缩放、平移、光标读值 |
| F5.2 | 井位处预测曲线与实测曲线对比 |
| F5.3 | 指标：RMSE、MAE、MAPE、SSIM、R²；全场与盲井分别统计 |
| F5.4 | 留一法盲井检验：依次留出一口井，用其余井建模，统计留出井误差 |
| F5.5 | 多方法对比：在固定测试集上并列显示 AI 与各插值方法的指标 |
| F5.6 | 训练损失曲线显示 |

### F6 成果导出与报告（中）

| 编号 | 需求 |
|---|---|
| F6.1 | 速度场导出为 SEG-Y、NPY、BIN、CSV |
| F6.2 | 剖面图、对比图导出为 PNG、PDF |
| F6.3 | 自动生成精度评估报告（Markdown 或 HTML，含参数、指标表与图） |
| F6.4 | 模型权重与训练记录的列表、删除、导出 |

## 5 算法验收指标

在 Marmousi2 合成数据的固定测试集上：

- 预测速度场 MAPE ≤ 8%（预期目标）
- 盲井处 RMSE 比 IDW 与克里金基线降低 20%（预期目标）
- 以实测结果为准，未达标时在报告中如实说明并分析原因

## 6 数据需求

详细来源、MD5 与格式见 `data/README.md`。

| 数据 | 用途 | 格式 |
|---|---|---|
| 官方 Marmousi2 纵波速度，抽样为 2721×701（6.25 m × 5 m） | 主实验训练与定量评估的真值 | SEG-Y → NPY |

| Central Valley 243 口井 Vp 曲线 | 测井清洗与粗化的补充验证 | ASCII |
| Devito 版 Marmousi 子块、OpenFWI 样例 | 单元测试与快速调试 | BIN / NPY |

工程库实体：工程、数据体、井、测井曲线、建模任务、评估记录，详见设计说明书。

## 7 外部接口

- 用户界面：PySide6 桌面窗口，布局见设计说明书。
- 软件接口：numpy、segyio、lasio、pandas、scipy、scikit-learn、PyKrige、PyTorch、sqlite3。
- 硬件接口：通过 PyTorch 使用 NVIDIA CUDA 显卡。
- 命令行接口：算法层提供训练、预测、评估的命令行脚本，便于批量实验。

## 8 用例

| 用例 | 参与者 | 主流程 | 异常流程 |
|---|---|---|---|
| UC1 导入数据 | 解释人员 | 选择文件 → 填写参数 → 校验 → 写入工程库并显示 | 校验失败：提示原因，不写入 |
